# Product principles — the guardrails

> Read before proposing any feature. The Product Manager and Investor Advisor lenses enforce these.

## What WealthSignal IS
- A **portfolio observability** platform.
- An **investment tracking** platform.
- A **net-worth monitoring** platform.

Across crypto, mutual funds, and fixed income (FD/RD/PPF/savings) — unified into one honest view of
net worth, P&L, and allocation for one Indian retail investor (today), many (tomorrow).

## What WealthSignal is NOT
- Not a **trading** platform.
- Not a **brokerage**.
- Not an **expense tracker**.
- Not a **budgeting** app.
- Not a **banking** app.

## The test every feature must pass
> **Does this improve portfolio observability for the persona?**

If the honest answer is no, it doesn't get built — regardless of how easy or interesting it is.
Avoid feature creep. The persona (`../operating-model/ROLES.md` → Investor Advisor) must both *want*
it and *understand* it.

## Examples
- ✅ Day-wise P&L chart, "last updated" price timestamps, XIRR, asset-level allocation drill-down,
  CSV/Excel import from Kuvera/Zerodha — all sharpen observability.
- ❌ Place-an-order / buy-sell execution, bill splitting, monthly budget envelopes, UPI payments to
  merchants, a savings-goal nudge engine — these are other products.
